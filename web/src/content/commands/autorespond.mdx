Requires admin access. `add` supports `match-type`, `use-llm`, `use-regex`, channel filters, mention requirements, chance, and trigger deletion. LLM auto-responses use the recent channel conversation cache for context before replying. `remove` deletes by trigger and `list` shows configured responses.
