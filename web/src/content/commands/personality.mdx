This command is only available in the Bhayanak server, and every reply is visible only to you.

## Viewing

- `/personality view user` shows your own user personality profile. Administrators can add `user:@someone` to view another member's profile; anyone else asking for another member gets a refusal.
- `/personality view guild` shows this server's culture profile. Any member can use it.

## How profiles are written

Profiles come from the messages archived in the Guess Who channel. A scheduled job builds them at bot startup and every 6 hours, so a profile appears within about 6 hours of enough eligible messages existing: 100 for a member, 200 for the server. After that a profile is refreshed once 20 new messages (member) or 40 (server) have arrived.

Each refresh rewrites the profile in place instead of adding to it, so a profile stays within about 1,500 characters. The bot uses the whole profile when it replies, which means what you see here is exactly what shapes its answers.

## Administrators

`/personality refresh user` and `/personality refresh guild` are for server administrators. They rewrite a profile now rather than waiting for the next scheduled run, as long as enough new messages have arrived and the profile was not refreshed in the last 5 minutes.

The `/config` personality setting is an operational feature toggle: when it is off, no profiles are built for the server, the commands say so, and the bot does not use profiles in replies.
